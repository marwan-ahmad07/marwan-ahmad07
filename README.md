### 🏆 Featured Projects

Here are some of my standout academic and personal projects that demonstrate my engineering problem-solving capabilities:

#### 🧠 Artificial Intelligence & Algorithms

- **[Sudoku CSP AI Solver](https://github.com/marwan-ahmad07/Artificial-Intelligence-)**: Developed a robust graphical Sudoku solver using Constraint Satisfaction Problem (CSP) techniques, implementing **Backtracking** and **Arc Consistency (AC-3/MAC)** algorithms with detailed search tree analysis and performance benchmarking.
- **[Connect 4 AI Engine](https://github.com/marwan-ahmad07/Artificial-Intelligence-/tree/main/lab2)**: Built a Connect 4 game featuring an AI opponent powered by **Minimax with Alpha-Beta Pruning**. Implemented advanced heuristics and real-time visualization of the AI's principal variation decision tree.

#### 📊 Machine Learning & Data Science

- **[Machine Learning Engineering Suite](https://github.com/marwan-ahmad07/Machine-Learning-Assignments)**: A highly rigorous collection of AI and data science models, featuring both from-scratch mathematical implementations and modern framework adaptations (PyTorch, Scikit-Learn):
  - **[Supervised Learning (Lab 1)](https://github.com/marwan-ahmad07/Machine-Learning-Assignments/tree/main/LAB1)**: Engineered **K-Nearest Neighbors** and **Linear Regression** architectures from scratch using pure NumPy to classify MAGIC Gamma Telescope data and predict housing prices.
  - **[Deep Neural Networks (Lab 2 & 3)](https://github.com/marwan-ahmad07/Machine-Learning-Assignments/tree/main/LAB2)**: Developed deep **Convolutional Neural Networks (CNNs)** and Feedforward Networks with PyTorch. Conducted advanced hyperparameter optimization, dropout regularization, and batch normalization analysis.
  - **[Unsupervised Learning (Lab 4)](https://github.com/marwan-ahmad07/Machine-Learning-Assignments/tree/main/LAB4)**: Hand-coded advanced dimensionality reduction and clustering algorithms entirely from scratch, including **PCA**, **K-Means**, **Gaussian Mixture Models (GMM)**, and an **Autoencoder Neural Network** utilizing manual backpropagation.

#### 🌐 Computer Networks & Infrastructure

- **[Advanced Networking Suite](https://github.com/marwan-ahmad07/Computer-Networks-)**: Engineered a comprehensive suite of networking applications spanning multiple OSI layers:
  - **[Transport Layer (Lab 1)](https://github.com/marwan-ahmad07/Computer-Networks-/tree/main/Lab1)**: Implemented low-level **TCP & UDP Socket Programming** architectures in Python to explore connection-oriented vs connectionless communications.
  - **[Application Layer (Lab 2 & 4)](https://github.com/marwan-ahmad07/Computer-Networks-/tree/main/Lab2)**: Built a fully functional **Email Client GUI** automating SMTP/IMAP protocols, and developed a custom **HTTP Server/Client** from scratch alongside a **Reliable UDP** protocol simulation.
  - **[Network Traffic Analysis (Lab 3)](https://github.com/marwan-ahmad07/Computer-Networks-/tree/main/Lab3)**: Conducted deep packet inspection and network troubleshooting using **Wireshark** to dissect encapsulation and trace specific payloads.
- **Dockerized Full-Stack Architecture**: Configured and debugged multi-container Docker environments (Node.js backend, React frontend, MySQL database), managing complex port-bindings and inter-container network communication.

#### 🏗️ Software Engineering & GUI Development

- **[Gym Membership Management System](https://github.com/marwan-ahmad07/Gym-Membership-Management-System)**: Engineered a complete management system in Java featuring a frontend GUI, backend logic, and an inference engine module.
- **GPA Calculator & Tracker**: Developed a robust Python application (CLI and GUI) with JSON-based data persistence for tracking academic history, credit hours, and dynamically calculating term/cumulative GPAs.
